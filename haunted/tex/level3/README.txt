Level 3 texture pack. Each texture: name.jpg (colour, sRGB) + name_n.jpg (tangent-space normal, OpenGL/three.js), 1024x1024, seamless unless noted.
Baked in Blender from src/level3_tex.py (shared generators: src/texlib.py, framework: src/texbake.py).

Where each one goes:
  clock_wood             The Clock Face (floor)
  echo_slate             The Echo Chamber (floor)
  gear_plates            The Gear Works (floor)
  bridge_planks          The Broken Bridge (floor): gappy, split planks
  memory_marble          The Memory Hall (floor)
  garden_cobble          The Dowsing Garden (floor)
  belfry_boards          The Bell Tower (floor): boards streaked with old bird droppings and rope burns
  lamp_grate             The Lamp Room (floor)
  star_chart             The Star Chart (floor)
  heart_brass            The Clock Heart (floor)
  clock_wall             walls (wallImg): dark walnut boards running up the tower
  brass_trim             trim (trimImg), rails, gear rims
  clock_face             clock dial (single image, not tiled): clock faces, hands-on dials
  bell_bronze            bells, bronze props
